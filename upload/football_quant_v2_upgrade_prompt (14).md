### ۲. تابع تصمیم‌گیری غیرخطی ۵ بعدی در «ایجنت سوپروایزر ارشد» (Non-Linear Bayesian Supervisor Gate)

به جای فیلتر خطی و صفر و یکی (`risk <= 10.5%`) که باعث سوختن `+1,402 واحد` سود در دفتر سایه شد، ایجنت سوپروایزر باید برای هر مسابقه، هر ۴ روش تک‌بازی (`Banker`, `Combo`, `Correct Score Cluster`, `Dual-Hedge`) را در ۱۰,۰۰۰ شبیه‌سازی مونت‌کارلو تست کند و بر اساس **تابع مطلوبیت غیرخطی نسبت شارپ و ارزش انتظاری (`Non-Linear Sharpe & Kelly Utility`)** زیر، بهترین روش `Bet Type` را برای آن مسابقه انتخاب کند:

```typescript
// تابع غیرخطی امتیازدهی سوپروایزر برای انتخاب بهترین Bet-Type در هر مسابقه
export function calculateNonLinearSupervisorScore(candidate: {
  winProb: number;          // احتمال برد کل استراتژی (یا مجموع پوشش خوشه)
  effectiveOdds: number;    // ضریب موثر کل پوزیشن (پس از داچینگ یا تک‌شرط)
  doubleWinProb: number;    // احتمال برد دوبل همزمان در نتایج 1-0 / 2-0
  entropy: number;          // آنتروپی شانون ماتریس 6x6
  leagueReliability: number;// ضریب اعتبار لیگ از کالیبراسیون (0.85 تا 1.15)
}): number {
  const netReturnOnWin = candidate.effectiveOdds - 1;
  const lossProb = 1 - candidate.winProb;
  const expectedValue = (candidate.winProb * netReturnOnWin) + (candidate.doubleWinProb * 0.45) - lossProb;
  const variance = (candidate.winProb * Math.pow(netReturnOnWin - expectedValue, 2)) +
                   (lossProb * Math.pow(-1 - expectedValue, 2));
  const sharpeRatio = expectedValue / Math.sqrt(Math.max(0.01, variance));

  // جریمه غیرخطی ریسک و پاداش آنتروپی پایین
  const nonLinearSafetyBonus = Math.pow(candidate.winProb, 2.2) * 100;
  const entropyBonus = Math.max(0, (2.8 - candidate.entropy) * 12);

  return Number(((sharpeRatio * 45 + nonLinearSafetyBonus * 0.55 + entropyBonus) * candidate.leagueReliability).toFixed(1));
}
```
- **قانون تایید هوشمند سوپروایزر:**
  اگر مسابقه‌ای در استراتژی `Dual-Hedge` ریسک ۱۱٪ یا ۱۳٪ داشت، سوپروایزر به جای وتو کردن کورکورانه، بلافاصله بررسی می‌کند که آیا آن مسابقه در استراتژی **`🧩 COMBO (مثلاً 1X & Under 3.5)`**، **`🏦 BANKER`** یا **`🎯 CORRECT SCORE CLUSTER (4-Score Dutching)`** دارای `ExpectedValue > +0.08` و `SharpeRatio > 0.32` هست یا خیر! در صورت مثبت بودن، بازی با آن `Bet Type` تخصصی تایید می‌شود و تنها بازی‌های واقعاً بی‌کیفیت و پرنوسان (مثل `esp.2` و `usa.1` یا بازی‌های دارای شارپ منفی در هر ۴ روش) وتو می‌شوند!
