### ۱. اصلاح فرمول ضریب در `src/lib/engine/orthogonal.ts` (کالیبراسیون دقیق با مارجین واقعی `1xBet`)

در فایل `src/lib/engine/orthogonal.ts` (خطوط ۲۵۷ تا ۲۸۵):
1. متغیر مصنوعی `edgeNudge = 1.02 + (seed % 7) * 0.01` را در تابع `computeValueMarketOdds` **به طور کامل حذف کن!**
2. ضریب هر مارکت مشتق‌شده از ماتریس ۶×۶ دیکسون-کولز را دقیقاً با **ضریب کارمزد استاندارد `1xBet` (`ONE_X_BET_PAYOUT_FACTOR = 0.945`)** محاسبه کن:
   ```typescript
   // فرمول واقعی ضریب تابلوی 1xBet (با ۵.۵٪ اورراند استاندارد بوک‌میکر):
   export function computeRealistic1xBetOdds(matrixProb: number, realMarketPrice?: number | null): number {
     if (realMarketPrice && realMarketPrice > 1.05) {
       return Number(realMarketPrice.toFixed(2));
     }
     const clampedProb = Math.max(0.04, Math.min(0.92, matrixProb));
     const realisticBookieOdds = 0.945 / clampedProb;
     return Number(Math.max(1.12, Math.min(9.50, realisticBookieOdds)).toFixed(2));
   }
   ```
3. به این ترتیب، ضریب نمایش‌داده‌شده روی کارت هیچ تورم مصنوعی نخواهد داشت و مستقیماً با تابلوی `1xBet` هم‌تراز می‌شود!
