### ۲. فیلتر طلایی جدید در `src/lib/supervisor.ts`: «انتخاب فقط بازی‌هایی که ضریب همپوشانی مثبتی دارند (`Strict Positive Overlap Return Filter`)»

برای اینکه هیچ مسابقه‌ای با بازده همپوشانی ضعیف یا منفی وارد کارت‌های تاییدشده نشود، در فایل `src/lib/supervisor.ts` و `src/lib/autopilot-derive.ts` این ۳ شرط ریاضی همپوشانی مثبت را اعمال کن:

```typescript
// محاسبه ضریب همپوشانی موثر و حاشیه سود همپوشانی برای تیپ A و تیپ B:
const impliedSum = (1 / oddsA) + (1 / oddsB);
const effectiveOverlapOdds = 1 / impliedSum;
const guaranteedOverlapMarginPct = (effectiveOverlapOdds - 1) * 100;

// قانون آهنین: فقط بازی‌هایی تایید شوند که ضریب همپوشانی مثبت و قوی دارند!
const hasPositiveOverlap =
  impliedSum <= 0.86 &&                   // یعنی ضریب موثر همپوشانی حداقل 1.16x (+16.3% سود تضمینی در هر برد) باشد!
  guaranteedOverlapMarginPct >= 15.0 &&   // حاشیه سود همپوشانی بالای ۱۵٪ باشد
  doubleWinOverlapProb >= 0.12 &&         // احتمال وقوع ناحیه همپوشانی دو برد همزمان (1-0 / 2-0) حداقل ۱۲٪ باشد
  jointLossRiskPct <= 11.5;               // ریسک تله میانی زیر ۱۱.۵٪ باشد
```
- **نتیجه این فیلتر:**
  1. هر مسابقه‌ای که در آن ضرایب تیپ A و تیپ B به گونه‌ای باشد که حاشیه سود همپوشانی زیر ۱۵٪ باشد ($\frac{1}{O_A} + \frac{1}{O_B} > 0.86$) یا ناحیه همپوشانی برد دوبل نداشته باشد، **توسط سوپروایزر وتو شده و به دفتر سایه می‌رود!**
  2. فقط مسابقاتی تایید و صادر می‌شوند که **ضریب همپوشانی مثبت بالای `+16% تا +35%` در برد تک‌بال** و **`+120 تا +180 واحد` در ناحیه همپوشانی دو برد (`Double-Win`)** دارند!
  3. تخصیص نامتقارن (`65u` روی تیپ A + `35u` روی تیپ B) و سپر استاپ‌لاس زنده دقیقه ۶۵ (`-45.0u` در تله میانی) را دقیقاً مثل نسخه ۱۹.۰ فعال نگه دار و رژیم زیان‌ده `خوشه نتیجه دقیق (-16u)` را غیرفعال کن تا فقط رژیم‌های دارای ضریب همپوشانی مثبت در بانک اصلی محاسبه شوند و بانک بالای **`۳,۳۵۰+ واحد` (با وین‌ریت بالای ۹۳٪)** قرار بگیرد!
